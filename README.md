# S.tand

밤에는 은은한 스탠드가 되고, 잠든 동안에는 필요한 수면 소리 구간만 기기에 저장하는 iPhone 앱입니다.

## 현재 구현 범위

- iPhone 가로 모드 전용 SwiftUI 화면
- 수동 탭 또는 박수형 순간 소리에 반응하는 점등
- 설정한 유지 시간이 지난 뒤 자연스럽게 줄어드는 불빛
- 마이크 입력을 기기 안에서 분석하고, 지속되는 소리 구간만 저장
- 소리 앞 0.8초와 뒤 1.4초를 함께 담아 잘림을 줄인 로컬 `.m4a` 녹음
- 저장된 수면 소리 재생, 공유, 개별 삭제
- 밝기, 유지 시간, 감광 시간, 마이크 민감도 설정
- 마이크 권한을 거부해도 사용할 수 있는 수동 스탠드

> 현재 단계의 감지는 의료용 코골이 판별이 아니라 음량 기반 **수면 소리 자동 녹음**입니다. 기침, 말소리, 문 닫는 소리 등이 함께 녹음될 수 있습니다.

## 실행

1. `STand.xcodeproj`를 Xcode에서 엽니다.
2. Signing & Capabilities에서 자신의 Team을 선택합니다.
3. 실제 iPhone을 가로로 놓고 실행합니다. 마이크 입력 검증은 실제 기기를 권장합니다.

명령줄 검증:

```sh
xcodebuild -project STand.xcodeproj -scheme STand \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath /tmp/STandDerivedData CODE_SIGNING_ALLOWED=NO build
```

## 중요한 iOS 제약

일반 iOS 앱은 잠긴 iPhone의 물리적 화면을 박수로 깨울 수 없습니다. S.tand는 취침 세션 중 자동 잠금을 막고, 앱 화면을 거의 검게 유지하다가 소리를 감지하면 앱의 불빛을 켭니다. 잠금 버튼을 누르거나 앱을 종료하면 박수 점등은 동작하지 않습니다.

오디오 파일은 Application Support의 앱 전용 폴더에만 저장되며, 사용자가 공유 버튼을 누르기 전에는 기기 밖으로 전송하지 않습니다. 주변 사람의 목소리도 녹음될 수 있으므로 함께 있는 사람에게 먼저 알려 주세요.

## 버전 정책

- 앱 버전: `1.0.0` 고정 (별도 지시가 있을 때만 변경)
- 빌드 번호: `0.0.0`에서 시작
- 작은 수정: 마지막 자리 증가 (`0.0.1`, `0.0.2`, ...)
- 비교적 큰 수정: 가운데 자리 증가 (`0.1.0`, `0.2.0`, ...)

자세한 규칙은 [`docs/VERSIONING.md`](docs/VERSIONING.md)에 기록되어 있습니다. 현재 제품 결정과 다음 논의 항목은 [`docs/PRODUCT.md`](docs/PRODUCT.md)에 정리했습니다.
