# S.tand

밤에는 은은한 스탠드가 되고, 잠든 동안에는 필요한 수면 소리 구간만 기기에 저장하는 iPhone 앱입니다.

## 현재 구현 범위

- iPhone 세로·가로 반응형 SwiftUI 화면과 기기 설정 따르기·방향 고정 설정
- 메인 화면에서 현재 방향을 즉시 고정하거나 해제하는 아이콘·텍스트 버튼
- 수동 탭 또는 박수형 순간 소리에 반응하는 점등
- 설정한 유지 시간이 지난 뒤 자연스럽게 줄어드는 불빛
- 선택 시 화면 점등과 함께 플래시를 켜고 같은 감광 곡선으로 서서히 끄는 기능
- 뒤척임으로 추정한 소리에 화면과 플래시를 켤 수 있는 선택 설정
- 소리 길이, 저주파 비율, 피크와 영점 교차율로 코골이·뒤척임·기타 소리를 기기 안에서 구분
- 코골이로 추정한 소리 구간만 저장
- 소리 앞 0.8초와 뒤 1.4초를 함께 담아 잘림을 줄인 로컬 `.m4a` 녹음
- 저장된 수면 소리 재생·일시정지, 하단 진행바 탐색, 공유, 개별 삭제
- 여러 수면 소리를 시간순으로 이어 붙인 하나의 `.m4a` 파일 생성
- 화면·플래시 밝기, 유지 시간, 감광 시간, 마이크 민감도 설정
- 날짜와 시간을 보여주는 플립시계 및 감광 후 희미한 실루엣 표시
- 배터리 잔량·충전 상태 표시와 미충전 20% 이하 자동 중지
- 마이크 권한을 거부해도 사용할 수 있는 수동 스탠드

> 현재 단계의 코골이·뒤척임 구분은 의료용 판별 모델이 아니라 소리 특징 기반 휴리스틱입니다. 실제 침실 환경에 따라 오분류될 수 있습니다.

개발, 테스트, 실기기 설치, Git 배포, 버전 관리에 관한 모든 규칙은 루트의 [`AGENTS.md`](AGENTS.md)만을 단일 원본으로 사용합니다.

## 중요한 iOS 제약

일반 iOS 앱은 잠긴 iPhone의 물리적 화면을 박수로 깨울 수 없습니다. S.tand는 실행 중 자동 잠금을 막고, 취침 세션 중 플립시계와 정보를 거의 보이지 않는 실루엣 밝기로 유지합니다. 박수형 소리, 뒤척임 추정 또는 화면 터치를 감지하면 앱의 불빛을 켭니다. 잠금 버튼을 누르거나 앱을 종료하면 소리 점등은 동작하지 않습니다.

오디오 파일은 Application Support의 앱 전용 폴더에만 저장되며, 사용자가 공유 버튼을 누르기 전에는 기기 밖으로 전송하지 않습니다. 주변 사람의 목소리도 녹음될 수 있으므로 함께 있는 사람에게 먼저 알려 주세요.

현재 제품 결정과 다음 논의 항목은 [`docs/PRODUCT.md`](docs/PRODUCT.md)에 정리했습니다.
