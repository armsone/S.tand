## 오류 원인·수정·재발 방지

1. Gemini 검토 래퍼가 존재하지 않는 `.github` 경로를 검색해 외부 도구 오류로 끝났다. 앱 컴파일 오류가 아니었으며, 이후 선택 경로의 존재를 먼저 확인하도록 작업 절차를 바꿨다.
2. Claude 실행은 5시간 세션 한도 도달로 중단됐다. 작성 중인 결과를 폐기하지 않고 Gemini가 같은 계약을 이어받았고 Codex가 제출 근거와 영향 범위를 검증했다.
3. iOS UI 카탈로그가 앱 전체 왼쪽 가장자리에서 스크롤해 홈 전역 제스처와 무한 마키 타임라인을 건드렸다. UI 카탈로그에서 마키를 정지하고 설정 `ScrollView`에 직접 표준 스와이프를 보내도록 수정했으며 전체 카탈로그 재실행이 통과했다.
4. Release Catalyst 빌드에서 DEBUG 전용 `disablesAnimations`가 비-DEBUG 분기에 없어 컴파일에 실패했다. Release 분기에 `false` 상수를 추가했고 서명 Release 빌드가 통과했다.
5. Android 계측 테스트 첫 실행은 종료된 `emulator-5554`를 지정해 실패했다. Google TV AVD의 부팅 완료를 확인한 뒤 재실행해 4개 테스트를 통과시켰다.
6. Android 수동 확인 중 취소 뒤 늦은 네트워크 결과가 다시 열릴 수 있는 경쟁 조건을 찾았다. 짧은 확인 단계는 완료 전 닫히지 않게 하고 서비스의 dismiss가 Checking/Downloading 상태를 무시하도록 수정했다.

## 사용 불가 대상

- SM-T500은 기존 무선 주소와 현재 서브넷의 TCP 5555 검색에서 발견되지 않아 설치하지 못했다. 연결된 Android 휴대전화와 Google TV AVD 검증은 완료했다.
