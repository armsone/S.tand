## 오류와 재발 방지

1. 통합 행 첫 컴파일에서 nullable 라디오 참조 3곳과 기존 `Check` 아이콘 import 누락을 발견했다. nullable guard와 import를 복구하고 동일 빌드를 재실행해 통과시켰다.
2. 독립 열 전환 시 기존 Grid의 `verticalArrangement`를 Staggered Grid에 그대로 사용해 컴파일이 실패했다. 해당 API의 `verticalItemSpacing`으로 교체하고 테스트·빌드를 다시 통과시켰다.
3. 새 셸에서 `adb`가 PATH에 없어 설치가 실패했다. 이후 모든 에뮬레이터 명령은 `/Users/armsone/Library/Android/sdk/platform-tools/adb` 절대 경로를 사용했다.
4. 홈페이지 Sites 버전 저장이 전용 저장소의 이전 HEAD 때문에 한 번 거부됐다. GitHub 푸시와 Sites 소스 푸시를 분리해 확인한 뒤 현재 커밋을 Sites 저장소에도 올리고 재시도했다.
5. 다른 앱의 이미지 뷰어 지시가 S.tand 대화에 잘못 들어온 것을 확인했다. NasFinder 앱은 읽기만 했고 변경하지 않았으며, S.tand에 잠시 적용한 상태 표시줄 변경은 즉시 원복했다.
