# 버전 관리 규칙

S.tand는 사용자의 별도 지시 전까지 아래 규칙을 유지합니다.

| 구분 | Xcode 설정 | 현재 값 | 변경 규칙 |
| --- | --- | --- | --- |
| 앱 버전 | `MARKETING_VERSION` | `1.0.0` | 특별한 지시가 있을 때만 변경 |
| 빌드 번호 | `CURRENT_PROJECT_VERSION` | `0.0.0` | 변경 규모에 따라 증가 |

## 빌드 번호 증가

- 문구, 간격, 작은 버그 수정 등 작은 변경: `0.0.x`를 1 증가
- 사용자 흐름 또는 기능 단위의 비교적 큰 변경: `0.x.0`을 1 증가하고 마지막 자리를 0으로 초기화
- 이 저장소를 처음 만든 현재 상태는 `0.0.0`

각 커밋에서 빌드 번호를 자동으로 올리지 않습니다. 변경의 크기를 판단한 뒤 명시적으로 올려 의도하지 않은 버전 변경을 막습니다.
