# S.tand 제품 기준

## 한 문장 설명

S.tand는 밤새 곁에서 플립시계·날씨 변화·안전 상태를 조용히 보여주고, 뒤척임에는 불빛으로 반응하며 코골이는 기록하는 잠자리 케어 앱입니다.

## 현재 결정

- iPhone·iPad 지원, 세로·가로 회전 및 iPad 전체 화면 실행
- 설정에서 기기 설정 따르기, 세로 고정, 가로 고정 중 선택
- 방향 고정은 설정의 자동·세로·가로 선택에서만 제공하며 메인 화면 버튼은 두지 않음
- 앱 실행 시 최초 안내 화면 없이 취침 세션과 마이크 감지를 자동으로 시작
- 앱이 전면에 있는 동안 자동 잠금을 막고, 감광 후에는 날짜·플립시계·배터리를 거의 보이지 않는 실루엣으로 유지
- 자동 모드에서 화면을 잠그거나 다른 앱으로 이동하면 즉시 매이트 모드로 전환하고, 백그라운드 오디오 감시와 같은 잠자리 세션을 유지
- 홈 상단에서 `방 소리 익히는 중`, `소리 감시 중`, `소리 저장 중`, 권한·시작 실패 상태를 실제 마이크 상태에 맞춰 표시
- 야간 세션은 설정된 조명 밝기로 시작하고 유지·감광 시간을 거쳐 실루엣으로 전환
- 좌우 드래그는 감광 대기시간을 10초~5분으로 바꾸며, 밝은 화면 값이 감지되면 자동 감광을 보류한다.
- 밝은 상태의 화면 탭은 즉시 자연 감광하고, 어두운 상태의 화면 탭은 조명을 켠다.
- 현재 위치 기반 날씨 아이콘·기온·체감온도를 표시하며 세로 모드에서는 시계 위치를 유지한 채 위쪽에 겹쳐 배치한다.
- 감광 중 화면 탭, 날카로운 손소리, 마찰·뒤척임 소리, 기기 움직임 및 시스템 밝기 급상승은 조명을 다시 켠다.
- 잠금화면 액세서리 원형 위젯은 한 칸으로 앱을 바로 실행한다.
- 녹음 목록은 행 탭 재생과 하단 진행바를 제공하며, 도구 메뉴의 선택 모드에서 병합 대상을 고른다.
- 플립시계는 부드러운 숫자 전환과 오른쪽 아래의 작은 초 표시를 제공한다.
- 핀치로 시계 크기를 조절하고 시스템 둥근체 및 6종 내장 서체 중에서 선택하며 설정값을 유지
- 박수형 소리 또는 화면 터치에 반응해 불빛과 조작부를 표시
- 점등은 0.3초 동안 부드럽게, 기본 60초 유지 후 30초 동안 감광
- 선택 설정으로 화면 점등 시 후면 플래시를 함께 켜고 화면 감광 비율에 맞춰 서서히 끔
- 소리 길이, 저주파 비율, 순간 피크와 영점 교차율을 조합해 코골이·뒤척임·기타로 기기 내 분류
- 선택 설정으로 뒤척임 추정 시 점등하며 실제 환경에서 오분류될 수 있음을 안내
- 코골이로 추정한 소리만 `.m4a` 구간으로 저장
- 녹음 구간 앞 0.8초와 뒤 1.4초를 포함해 시작과 끝이 잘리는 현상을 완화
- 저장된 녹음은 왼쪽 재생 버튼과 하단 진행바로 듣고 원하는 위치로 이동 가능
- 선택한 두 개 이상의 원본이나 오늘 저장된 원본을 시간순으로 이어 붙여 새 `.m4a` 합본을 만들며 원본과 이전 합본은 보존
- 계정, 서버, 광고 SDK, 분석 SDK, 클라우드 업로드 없음
- 마이크 권한을 거부해도 수동 불빛은 사용 가능
- 배터리 잔량과 충전 상태를 표시하고 미충전 상태에서 20% 이하가 되면 감지·녹음·불빛·플래시를 중지
- 수면 진단이나 의료적 판단을 제공하지 않음

## 플랫폼 제약

iOS는 일반 앱이 잠긴 화면을 박수로 깨우는 것을 허용하지 않습니다. 따라서 박수 점등은 앱이 전면에 있고 취침 세션이 실행 중일 때만 동작합니다. 다만 매이트 모드의 마이크 감시와 수면 소리 기록은 백그라운드 오디오 모드로 이어집니다.

## 다음 대화에서 정할 것

- 따뜻한 불빛 색상 프리셋과 색상 직접 선택 여부
- 녹음 자동 삭제 기간과 저장 공간 한도
- 아침 세션 요약과 날짜별 묶음 방식
- 실제 침실 샘플을 이용한 코골이·뒤척임 분류 기준 보정과 Core ML 모델 도입 여부
- WeatherKit 현재 날씨와 의미 있는 야간 날씨 변화 표시
- 앱 아이콘과 최종 브랜드 디자인
