# S.tand 제품 기준

## 한 문장 설명

S.tand는 가로로 놓은 iPhone을 조용한 야간 스탠드로 사용하면서, 잠든 사이 발생한 수면 소리 구간을 기기 안에 남기는 앱입니다.

## 현재 결정

- iPhone 전용, 가로 방향만 지원
- 사용자가 명시적으로 `취침 시작`을 눌러야 마이크 감지를 시작
- 취침 세션 동안 자동 잠금을 막고, 앱 화면을 검게 낮춘 상태에서 박수형 소리에 반응
- 점등은 0.3초 동안 부드럽게, 기본 60초 유지 후 30초 동안 감광
- 녹음은 기기 안에서 음량을 분석해 지속되는 소리만 `.m4a` 구간으로 저장
- 녹음 구간 앞 0.8초와 뒤 1.4초를 포함해 시작과 끝이 잘리는 현상을 완화
- 계정, 서버, 광고 SDK, 분석 SDK, 클라우드 업로드 없음
- 마이크 권한을 거부해도 수동 불빛은 사용 가능
- 수면 진단이나 의료적 판단을 제공하지 않음

## 플랫폼 제약

iOS는 일반 앱이 잠긴 화면을 박수로 깨우는 것을 허용하지 않습니다. 따라서 박수 점등은 앱이 전면에 있고 취침 세션이 실행 중일 때만 동작합니다. 현재 버전은 백그라운드 오디오 모드를 선언하지 않습니다.

## 다음 대화에서 정할 것

- 따뜻한 불빛 색상 프리셋과 색상 직접 선택 여부
- 녹음 자동 삭제 기간과 저장 공간 한도
- 아침 세션 요약과 날짜별 묶음 방식
- 실제 코골이 추정 모델 도입 여부와 오감지 기준
- 잠금 중 녹음을 위한 백그라운드 모드 지원 여부
- 앱 아이콘과 최종 브랜드 디자인
