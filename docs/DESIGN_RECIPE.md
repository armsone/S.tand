# S.tand 디자인 레시피

이 문서는 S.tand iOS와 Android가 같은 제품처럼 보이고 동작하기 위한 공통 기준이다. 화면을 새로 만들거나 기존 화면을 고칠 때 기억이나 스크린샷만으로 재구성하지 말고, 이 문서와 현재 iOS 소스를 함께 확인한다.

## 1. 제품의 인상

S.tand는 낮에는 책상 위의 조용한 오브제이고, 밤에는 잠자리를 살피는 매이트다. 고급스럽고 약간 유머러스하지만 사용자를 재촉하지 않으며, 있는 듯 없는 듯 생활의 일부가 되어야 한다.

- 장식보다 시간·날씨·상태의 즉시 인지가 우선이다.
- 어두운 방에서 눈부시지 않도록 검정과 낮은 명도의 유리를 기본 재료로 쓴다.
- 설명은 짧고 자연스러운 한국어로 쓴다. 같은 말을 제목과 보조 문구에 반복하지 않는다.
- 기능을 숨기지 않되, 평소 화면에는 꼭 필요한 정보와 행동만 남긴다.
- 의료 진단을 암시하지 않고 `후보`, `추정`, `수면 소리`처럼 정직한 표현을 쓴다.

## 2. 세 가지 핵심 상태

| 상태 | 역할 | 화면과 센서 |
|---|---|---|
| 오브제 모드 | 밝은 환경의 데스크 시계·날씨 오브제 | 밝은 화면 유지, 수면 소리 감시·녹음 중지, 후면 플래시 사용 안 함 |
| 매이트 모드 | 어두운 환경의 잠자리 동반자 | 최소 밝기의 시계·날씨 유지, 뒤척임 감시, 코골이·잠꼬대 후보만 녹음 |
| 화들짝 모드 | 매이트가 움직임에 잠깐 반응하는 순간 상태 | 화면과 설정된 보조 플래시를 잠시 켠 뒤 자연스럽게 매이트로 복귀 |

기본 모드는 `자동`이다. 어두움이 안정적으로 파악되면 1분 안에 매이트로 전환하고, 밝아질 때는 순간 조명인지 실제 기상인지 조금 더 신중하게 확인한다. 사용자는 언제든 `오브제 유지` 또는 `매이트 유지`를 선택할 수 있어야 한다.

## 3. 색과 표면

### 컬러 테마

- 바탕은 검정을 기초로 한 따뜻한 오렌지 방사형 조명이다.
- 핵심 광원: `RGB(255, 158, 71)`에 현재 조명 세기 적용.
- 보조 광원: `RGB(242, 69, 15)`에 현재 조명 세기의 72% 적용.
- 가장자리는 검정이며 조명 세기가 낮아질수록 완전한 검정에 가까워진다.
- 활성 강조색은 시스템 Orange를 사용한다.

### 그레이스케일 테마

- 구성·명도·간격은 컬러 테마와 같고 색만 제거한다.
- 위험·배터리 보호처럼 의미가 있는 예외를 제외하면 불필요한 컬러를 남기지 않는다.

### 공통 유리 패널

일반 상태의 패널은 흰색을 매우 낮은 불투명도로 겹친 유리다.

- 위쪽 채움: 흰색 9.5%
- 아래쪽 채움: 흰색 5.2%
- 외곽선: 흰색 8%, 1pt/dp
- 어두운 상태 위쪽 채움: 흰색 1.4%
- 어두운 상태 아래쪽 채움: 흰색 0.8%
- 어두운 상태 외곽선: 흰색 1.8%
- 모서리는 원형이 아니라 연속형 둥근 모서리를 사용한다.
- 일반 정보 패널 모서리 18, 작은 제어 타일 13을 기준으로 크기에 비례시킨다.
- 별도의 불투명 회색 카드나 강한 그림자를 섞지 않는다.

플립 패널은 한가운데를 검은 선으로 긋지 않는다. 위·아래 표면 사이에 투명 간격을 두어 배경이 보이게 한다. 시계 글자에도 같은 위치의 투명 마스크를 적용해 숫자와 패널의 분할 위치가 정확히 일치해야 한다.

## 4. 플립시계와 글꼴

- 시·분은 각각 독립 플립 패널이며 콜론은 두 패널 사이에 둔다.
- 세로 기준 카드 `126×92`, 숫자 64pt, 가로 기준 카드 `164×116`, 숫자 82pt.
- 세로 분할 간격 4pt, 가로 분할 간격 3pt.
- 초는 분 카드 오른쪽 아래에 작게 표시한다. 일반 명도 40%, 매이트 명도 16%.
- 시계 패널 탭은 글꼴 목록을 열고, 다시 탭하면 닫는다.
- 편집 중 시계 더블 탭은 12시간제와 24시간제를 전환한다.
- 글꼴 선택 화면은 실제 플립 카드 미리보기로 보여 준다.

글꼴마다 실제 글리프 중심이 다르므로 다음은 64pt 기준 세로 보정값이며 다른 크기에서는 비례 적용한다.

| 글꼴 | 세로 보정 |
|---|---:|
| 시스템 둥근체 | -1.5pt |
| Pretendard | 0pt |
| Kakao Big Sans | -3pt |
| NanumGothic | +1.5pt |
| Tenada | +8pt |
| Black Han Sans | +1.5pt |
| Do Hyeon | +2.5pt |
| Paperlogy Bold | 0pt |
| NEXON Lv.1 Gothic | +3.5pt |
| Poppins | +0.5pt |

폰트 보정의 목표는 텍스트 프레임의 수학적 중심이 아니라 보이는 숫자 글리프의 상·하 여백과 투명 분할 간격을 패널 중심에 맞추는 것이다.

## 5. 날씨·날짜·상태·배터리

- 날씨는 아이콘, 온도, 상태의 세 조각으로 구성한다.
- 조각이 합쳐지면 외곽선과 배경이 하나의 패널처럼 보여야 한다.
- 편집 중 날씨 조각끼리 40% 이상 겹치면 결합하고, 더블 탭하면 다시 분리한다.
- 위치 화살표는 iOS의 기본 위치 심벌을 사용하고 지역명 앞에서 고정한다. 지역명만 폭을 넘을 때 천천히 왕복한다.
- 온도 숫자를 패널의 시각적 중앙에 두고 위치명과 체감온도를 그 위·아래에 균형 있게 둔다.
- 날짜는 한 줄을 우선하되 정상적인 날짜가 말줄임표로 바뀌지 않도록 충분한 폭과 축소 여유를 둔다.
- 상태 문구는 한 줄을 우선하고 `현재 상태 · 오브제 모드`처럼 모드가 즉시 읽혀야 한다.
- 매이트 모드 배터리 패널은 다른 정보 패널과 같은 유리 재료를 쓴다.

## 6. 화면 제스처와 편집

일반 화면:

- 좌우 드래그: 어두워지기까지의 대기 시간 조절.
- 상하 드래그: 현재 화면 조명 밝기 조절. 어두운 상태에서는 매이트 정보 밝기를 조절.
- 한 번 탭: 밝은 화면은 자연 감광, 어두운 화면은 점등.
- 천천히 두 번 탭: 숨겨진 하단 기능 버튼 표시·숨김.
- 롱 프레스: 정보 패널 편집 진입.
- 핀치: 모든 정보 패널을 하나의 구성으로 보고 전체 크기를 조절.

패널 편집:

- 시계·날씨·날짜·상태·배터리·라디오 패널만 편집한다. 하단 기능 버튼 순서는 별도 편집 화면에서 바꾼다.
- 패널 이동 범위를 상·하단 가이드로 제한하지 않는다.
- 가로·세로 중앙선을 표시하고, 패널 중심이 자기 폭 또는 높이의 5% 안에 들어오면 자석처럼 정확히 붙인다.
- 시계도 위치와 크기를 바꿀 수 있다.
- 핀치 또는 왼쪽 위 조절점으로 중심을 유지한 채 30~200% 크기를 조절한다.
- 세로·가로 배치를 독립 저장한다.
- `초기화`는 현재 방향의 추천 배치로, `저장`은 현재 초안으로 확정한다.

하단 기능 버튼:

- 같은 크기·모서리·플립 간격·글자 계층을 사용한다.
- 각 행의 좌우 끝이 화면 여백에 맞고, 좌우 여백은 버튼 사이 간격과 같아 보이게 한다.
- 버튼 패널 롱 프레스는 버튼 순서 편집만 연다.
- 최소 터치 영역은 iOS 44×44pt, Android 48×48dp다.

## 7. 설정 화면

- 검정 단색 Form이 아니라 홈과 같은 따뜻한 방사형 배경과 유리 카드를 사용한다.
- 상단에는 현재 모드와 핵심 상태를 보여 주고, 바로 제어 → 화면과 시계 → 조명과 전환 → 감지와 수면 소리 → 연결과 정보 순서로 구성한다.
- 제목은 행동 또는 대상 한 번만 말하고, 보조 문구에서 같은 단어를 반복하지 않는다.
- 이모지는 장식으로 쓰지 않고 시스템 심벌을 사용한다.
- 긴 설명을 토글 옆에 억지로 넣지 말고 카드 아래의 짧은 도움말로 분리한다.
- 활성·비활성은 색만으로 구별하지 않고 문구·아이콘·명도도 함께 바꾼다.
- 홈에서 가능한 핵심 제어는 설정에서도 가능해야 하지만, 동일 기능을 서로 다른 이름으로 만들지 않는다.

## 8. 수면 소리 화면

- 기본 화면에는 잠자리별 가로 타임라인 카드만 먼저 보이고, 사용자가 탭할 때 녹음 목록을 펼친다.
- 잠자기 모드가 끝난 뒤 30분 안에 다시 들어오면 잠깐 깬 것으로 보고 같은 잠자리로 이어 기록한다. 과거 기록에 모드 시각이 없을 때만 별도의 90분 녹음 간격 추정을 사용하고 `시간 추정`으로 표시한다.
- 코골이·잠꼬대 후보는 보통 마커, 화들짝 작동 구간은 더 얇은 선으로 표시한다.
- 오늘 소리를 한데 묶는 동작은 오늘 카드에 직접 둔다. 원본은 기본적으로 보존한다.
- 세션을 펼치면 체크, 즉시 재생, 진행바, 공유, 삭제가 가능해야 한다.
- 합본은 원본 세션과 섞지 않고 별도 접힘 영역으로 둔다.
- 병합 중에는 원본 삭제나 전체 삭제처럼 결과를 깨뜨릴 수 있는 작업을 잠근다.
- 큰 글자에서는 카드와 작업 버튼을 1~2열 또는 세로 스택으로 바꾼다.

## 9. 인터넷 라디오 패널

세부 계약은 `docs/INTERNET_RADIO_BUTTON_DESIGN_SPEC.md`가 우선한다.

- 앱이 방송국·주소를 기본 제공하지 않는다. 사용자가 합법적인 HTTPS 스트림 주소를 직접 등록한다.
- 홈 하단 버튼이 아니라 시계·날씨와 같은 독립 정보 패널이다.
- 기준 크기 144×60, 기본 변환 `x=0.26`, `y=0.215`, `scale=0.75`.
- 패널 전경 흰색 78%, 보조 상태 52%, 공통 유리 패널 재료를 쓴다.
- 대기 `재생`, 연결 중 `연결 취소`, 재생 중 `감지·녹음 중지`, 실패 `연결 실패 · 다시 듣기`로 표시한다.
- 연결·재생 중에는 마이크 감지와 수면 녹음을 중지하고 움직임 감지는 유지한다.
- 포그라운드에서만 재생하며 백그라운드·오디오 포커스 손실·출력 기기 분리 시 정지한다.
- Safari/Chrome 공유는 편집 주소의 초안만 가져오며 사용자가 저장하기 전 기존 설정을 바꾸지 않는다.

## 10. 아이콘과 잠금화면

- 앱 아이콘은 확정된 데스크 오브제 심벌을 사용하고 Apple 시스템 마스크 안에서 답답하지 않은 여백과 시각 중심을 유지한다.
- 앱 내부 브랜드 아이콘도 같은 형상을 사용한다.
- 잠금화면 액세서리 원형 위젯은 컬러 앱 아이콘을 축소해 넣지 않고, 같은 오브제 형상을 원형 규격에 맞춘 투명 단색 템플릿으로 사용한다.
- 잠금화면의 vibrant 렌더링은 색을 보존하지 않으므로 형상과 여백의 동일성이 목표다.
- 정적 위젯 심벌에는 placeholder redaction이 적용되지 않도록 한다.

## 11. Android 구현 원칙

- Jetpack Compose에서도 숫자, 간격, 투명도, 상태 이름을 임의로 재해석하지 않는다.
- iOS의 SF Symbol은 가장 가까운 Material Symbols Rounded로 대응하되 의미가 먼저다.
- iOS 44pt 터치 영역은 Android에서 최소 48dp로 확장한다.
- 폰트 파일과 라이선스를 함께 옮기고 Android에서 실제 렌더링을 캡처해 글리프 중심 보정값을 별도로 검증한다. iOS 보정값을 무조건 그대로 쓰지 않는다.
- Media3/ExoPlayer 라디오는 포그라운드 재생만 허용하고 오디오 포커스를 획득·반납한다. 라디오 재생 중 마이크 감지와 녹음의 상호배제를 유지한다.
- 플랫폼 권한이나 제약이 다르면 기능을 숨겨 흉내 내지 말고 사용자에게 현재 상태를 분명히 알린다.
- 세로·가로, 컬러·그레이스케일, 일반·매이트, 기본·큰 글자, 최소 48dp 터치 영역을 모두 확인한다.

## 12. 변경 전후 확인표

- 제품 상태명이 오브제·매이트·화들짝으로 통일됐는가?
- 패널이 공통 유리 표면과 투명 플립 간격을 사용하는가?
- 숫자 글리프와 패널 분할 위치가 일치하는가?
- 날짜와 현재 상태가 정상 글자 크기에서 말줄임되지 않는가?
- 세로·가로 배치와 편집 결과가 각각 저장되는가?
- 날씨 결합은 40%, 중앙 자석은 5%, 패널 크기는 30~200%인가?
- 하단 버튼 편집과 정보 패널 편집이 분리됐는가?
- 매이트에서만 감지·녹음하고 라디오 재생 중에는 둘 다 멈추는가?
- 수면 기록이 잠자리 단위로 접혀 보이고 화들짝 구간이 구분되는가?
- VoiceOver/TalkBack, 큰 글자, Reduce Motion에서도 핵심 동작이 가능한가?
- 새 기능이 개인정보·권한·배터리 제약을 정직하게 설명하는가?
