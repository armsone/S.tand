# 보이소 Android

보이소는 아이 곁 기기(게스트)가 감지한 큰 소리와 지속되는 소리를 돌보는 사람의 기기(호스트)에 전달합니다. `무전기` 역할은 마이크를 사용하지 않고 호출 버튼을 눌렀을 때만 호스트 화면을 반응시킵니다. 소리를 녹음하거나 원음을 전송하지 않고, 감지 이벤트와 연결 상태만 공유합니다. 의료기기나 보호자의 직접 확인을 대신하지 않습니다.

## 연결 방식

- 같은 8자리 방 코드를 입력한 기기끼리 AES-256-GCM으로 암호화합니다.
- Wi-Fi에서는 게스트가 `_boyiso._tcp` 서비스를 알리고 호스트가 여러 게스트에 동시에 연결합니다.
- Bluetooth LE에서는 게스트가 GATT peripheral, 호스트가 central로 동작합니다.
- 동일 이벤트를 Wi-Fi와 Bluetooth로 함께 보내고 UUID로 중복 제거합니다.
- 게스트와 무전기는 5초마다 heartbeat를 보내며, 호스트는 15초 동안 받지 못하면 연결된 기기에서 제외합니다.
- 무전기 호출은 3초 연타 방지를 적용하고, 호스트 화면을 밝게 반응시킵니다.

## 개발 환경

- Android Studio에서 `android/` 디렉터리를 프로젝트로 엽니다.
- compile/target SDK 37, min SDK 26, Java 17을 사용합니다.
- 게스트 실기기에는 마이크와 Bluetooth 권한이 필요합니다. 호스트는 Bluetooth 권한을 거부해도 같은 Wi-Fi 연결을 사용할 수 있습니다.

단위 테스트는 이벤트 중복 제거, BLE 분할·재조립, 큰 소리·지속 소리 감지, 무전기 호출 전송과 연타 방지를 다룹니다. 실제 Wi-Fi/BLE 이중 경로와 화면 반응은 두 대 이상의 실기기에서 추가 확인해야 합니다.
